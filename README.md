# Multimodal Search (Text-to-Image)

Реализация системы мультимодального поиска изображений по текстовому описанию (Track A).
Использует OpenAI CLIP для получения эмбеддингов и Qdrant для векторного поиска.

## Структура проекта

- `notebooks/multimodal_search.ipynb`: Основной код (загрузка данных, индексация, поиск).
- `docker-compose.yml`: Конфигурация для запуска Qdrant.
- `requirements.txt`: Список зависимостей.
- `data/`: Локальное хранилище скачанных изображений (создается автоматически).

## Запуск

1. **Окружение**
   Создайте и активируйте виртуальное окружение, установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск базы данных**
   Поднимите Qdrant в Docker:
   ```bash
   docker-compose up -d
   ```
   *Убедитесь, что порты 6333 заняты Qdrant.*

3. **Работа с ноутбуком**
   Откройте `notebooks/multimodal_search.ipynb` и выполните ячейки последовательно.
   
   В ноутбуке реализованы шаги:
   - Эмбеддинг текста и изображений через CLIP.
   - Сохранение векторов в Qdrant.
   - Поиск топ-N картинок по текстовому запросу.
   - Оценка качества (Recall@K).

## Описание решения

- **Модель**: `openai/clip-vit-base-patch32`. Хороший баланс скорости и качества.
- **Данные**: Google Conceptual Captions (Validation Split). Скачиваются локально.
- **Векторная БД**: Qdrant. Используется Cosine Distance.

## Примеры запросов

- "собака на пляже"
- "красный автомобиль"
- "люди играют в футбол"
