# Дообучение LLM и интеграция с инструментами

Этот проект демонстрирует дообучение большой языковой модели (LLM) с использованием LoRA (Low-Rank Adaptation) и её интеграцию с внешними инструментами через LangChain.

## Описание проекта

Цель — адаптировать базовую модель для лучшего выполнения инструкций (Трек C) и расширить её возможности с помощью пользовательских функций.

### Выбранный трек: C (Инструктивный помощник)
- **Датасет**: `mlabonne/FineTome-100k`
- **Фокус**: Улучшение следования инструкциям и структурированные ответы.
- **Инструменты**: Утилиты для форматирования текста и валидации контента.

## Установка

1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # venv\Scripts\activate  # Windows
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Откройте `solution.ipynb`, чтобы изучить пайплайн обучения и демонстрацию интеграции инструментов.

Ноутбук охватывает следующие этапы:
1. Подготовка данных.
2. Конфигурация LoRA и дообучение (fine-tuning).
3. Определение пользовательских инструментов LangChain.
4. Примеры инференса и работы агента.
