# Реализация RAG-системы с использованием ChromaDB

Проект демонстрирует создание системы поиска по документам (Retrieval-Augmented Generation) на базе векторной базы данных ChromaDB. В качестве источника данных используется датасет новостей Gazeta.ru.

## Функциональность

*   **Подготовка данных**: Загрузка и предварительная обработка датасета новостей (IlyaGusev/gazeta).
*   **Векторизация**: Генерация семантических эмбеддингов с помощью модели `intfloat/multilingual-e5-base`.
*   **Индексация**: Сохранение векторов и метаданных в ChromaDB. Использование алгоритма HNSW для эффективного приближенного поиска.
*   **Поиск**: Реализация функций семантического поиска и гибридной фильтрации по метаданным (категориям).
*   **Производительность**: Скрипты для замера скорости поиска и пакетной обработки запросов.

## Установка и запуск

1.  Создайте и активируйте виртуальное окружение:
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

2.  Установите необходимые зависимости:
    ```bash
    pip install chromadb sentence-transformers pandas notebook datasets
    ```

3.  Запустите Jupyter Notebook:
    ```bash
    jupyter notebook task6_rag.ipynb
    ```
